# Attribution and distribution scope

This project is based on the LeRobot/SmolVLA, DexGraspVLA and DINOv2 communities. Base models and prior interface implementations are not claimed as new methods from this repository.

The supplied LeRobot modules carry Apache-2.0 headers. Their copyright headers are retained and the supplied license text is included at integrations/smolvla/LICENSE. Patch baselines, file hashes and snapshot markers are recorded in evidence/source_provenance.json. The provided snapshot contains local changes; it must not be confused with a clean upstream checkout.

No license was provided for the DexGraspVLA snapshot, and its public repository metadata did not declare one at inspection time. Its full code is not redistributed here. This repository publishes interface documentation, provenance hashes, independently written mathematical reference code, and selected non-sensitive experiment records instead.

No blanket license is selected for other independent artifacts in this repository. Dataset files, checkpoints, robot SDKs, device configuration and credentials are excluded. The provided real-robot video is a qualitative demonstration with unknown model/checkpoint attribution, not a controlled performance result.
