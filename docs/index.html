SmolVLA · 稠密视觉融合

保留全局视觉分支，新增冻结DINOv2-B/14工作区特征。37×37 patch网格投影至720维，以8头交叉注意力融入动作专家。

零初始化残差门控维持热启动输出一致；特征及K/V在10步去噪内复用。保留材料中的实际模块与集成补丁。

DexGraspVLA · 位姿/力分离

位姿与手部25D、五指实测力5D分别编码和归一化，公开预测边界合为30D；以流匹配速度场生成动作块。

力输出表示未来实测反馈，不能当作力控命令。本适配分支不含高层VLM planner、分割或跟踪模块。

绝对位姿重建 → 16步动作块 / 执行6步后重规划 → 模型与硬件适配器分离的推理边界

训练与数据工程

分组损失采用有效标量元素计数归约，处理各rank有效样本数不一致时的DDP权重；8卡BF16及分阶段微调配置单独保存。历史排查还覆盖了persistent DataLoader/PyAV worker的退出问题。

数据审计区分机器人反馈与遥操作指令，并保留RGB对齐误差分布。实际部署还需明确手部通道、单位、IK、传感器顺序与控制接口，不能将软件shape一致替代硬件验收。
