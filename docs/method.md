# 技术说明

## 统一动作表示

原始紧凑布局为 `ee_valid + xyz3 + quaternion_wxyz4 + hand_valid + hand16`，总宽度25；模型布局为 `xyz3 + rotation6D6 + canonical hand16`，同样宽度25。通过具名字段区分两种布局并重排手部通道，rotation6D按旋转矩阵前两列逐列拼接。

当前观测定义锚点 `(p_a, R_a)`。对动作块中每个目标 `(p_t, R_t)`，训练用 `Δp=p_t-p_a`、`ΔR=R_t R_aᵀ`；推理用 `p_t=Δp+p_a`、`R_t=ΔR R_a`。所有16个目标共享同一锚点，不逐帧累计积分。手部16维保持绝对值。

适配器的23D位姿接口为xyz3+quaternion_xyzw4+hand16；接口约定包含手部通道、单位与IK映射，参考实现采用canonical手顺序。

## SmolVLA：分组损失与DDP计数

损失按xyz、rotation6D、hand分组，组内按有效标量元素平均，再用配置权重合并。selected66 JC-parity配置权重为3/6/16、包括全部16个动作时域，尾部重复最终动作。

若各rank有效计数不同，简单平均局部均值会有偏差。实现all-reduce detached有效计数，并将每个rank的可微分子乘 `world_size/global_count`；经DDP梯度平均后得到全局有效元素均值对应的梯度。reference测试覆盖计数公式及不等有效计数输入。

## SmolVLA：稠密DINO视觉

同一720×1280 RGB进入全局SmolVLM分支和工作区DINO分支。后者取ROI `(480,0,1200,720)`，缩放518×518，经冻结DINOv2 ViT-B/14产生37×37 patch网格。1369个768维token投影到720维，通过8头cross-attention在action_out_proj前注入动作专家。

逐通道tanh残差gate初始为0，历史审计显示固定样本/噪声下扩展策略与基础策略逐元素一致，形状 `(1,16,25)`、最大差0.0。DINO编码及K/V投影在10步流匹配去噪间缓存复用。

阶段1训练记录包含3,155,760个适配/交叉注意力参数；历史文件给出18,200步checkpoint哈希。阶段2配置联合微调动作专家及视觉扩展，审计记录一次真实反向检查有103,019,945个可训练参数。

## DexGraspVLA：位姿/力分支

位姿与手部25D分支、五指实测力5D分支分别编码和归一化；模型输入保留两者语义边界，预测合并成30D。力分支的学习目标为未来实测力反馈，执行端从25D位姿/手部控制分支提取运动指令。

流匹配实现使用噪声与数据间的线性路径，训练速度场，支持基于Hungarian匹配的噪声配对；推理使用10步Euler积分。此分支移除了高层VLM planner及分割/跟踪模块，是低层视觉动作控制器的适配实验。

## 动作块执行接口

动作块16步，执行6步后重规划，目标频率10Hz。代码以mock、dry-run和显式execute模式组织执行入口，并将模型预测、绝对位姿重建及硬件适配器分别封装。
